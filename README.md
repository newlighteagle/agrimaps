# AgriMaps

Agriculture maps for the **#30DayMapChallenge 2026**, built from scratch
while learning TypeScript and Python.

🌐 Live: https://agrimaps.sofyansalim.my.id (coming soon)

## Structure

| Folder  | What                                                                     | Stack                          |
| ------- | ------------------------------------------------------------------------ | ------------------------------ |
| `web/`  | Website: landing page, gallery, and one page per map                     | Vite + TypeScript + OpenLayers |
| `data/` | Scripts that download and process open data into small files for the web | Python (uv) + DuckDB           |
